# 생성형 AI 서술을 세 갈래로 갈랐다 + 플랫폼 안 응답 기능 제언 (2026-09-08)

## 1. 소유자 지적 — 섞으면 안 되는 셋

> *「야 근데 웹 개발에만 쓴거지 산출물을 뭐 분해하고 그런건 웹 밖에서 코드로 한거지,
> 이거 조심해라, 그리고 서술형분석도 마찬가지 ai활용얘기가 나오면 안돼 원래」*

원고는 이 셋을 구분하지 않고 「생성형 AI를 썼다」로 묶어 두었다.

| | 무엇에 썼나 | 어디에 적나 |
|---|---|---|
| **플랫폼 개발** | 프론트엔드·백엔드 코드 초안, 오류 수정, 반복 구현 | 3.4 · 고지 절 |
| **산출값 검증** | **플랫폼 밖에서** 연구자가 별도 스크립트로 공개 자료를 직접 받아 분석 | 4.4 · 6장 · 고지 절 |
| **서술응답 부호화** | 문항별 정리와 후보 범주 제안까지. 분절·배정·확정은 연구자 | **고지 절만** |

**검증이 플랫폼 밖이라는 점이 중요하다.** 검증 대상과 검증 수단이 같은 코드면 확인이
성립하지 않는다. 4.4의 조건별 분해는 공개 자료를 별도로 받아 분석한 것이고 플랫폼의
화면이나 처리 경로를 거치지 않는다. 측광 마스크와 모델 적합만 플랫폼과 같은 함수를
호출해 「같은 방법」임을 보장했다.

## 2. 고친 것

**3.6** — 부호화 절차에서 도구 서술을 뺐다. 「초기 정리 단계에서는 생성형 AI를 …
보조 도구로 사용하였다. AI는 부호화자가 아니며…」 대신 **「부호화는 연구자가
수행하였다」**로 시작하고, 누가 무엇을 판정했는지만 적는다. 도구의 사용 범위는
고지 절로 넘겼다.

**「생성형 AI 활용 고지」 절** — 세 갈래로 갈라 적었다. 플랫폼 개발 / 플랫폼 밖의
검증 / 부호화 초기 정리. 특히 검증이 플랫폼 밖에서 이루어진 이유(검증 대상과 수단이
같으면 확인이 성립하지 않는다)를 밝혔다.

**6장** — 「본 연구에서는 문헌이 사용한 것과 같은 관측 자료를 받아 …분리하였다」 뒤에
**이 검증이 플랫폼 밖에서 수행되었다**는 문장을 넣었다.

## 3. 플랫폼 안의 응답·검토 기능을 제언에 넣었다 (6장 후속 과제 일곱째)

소유자 발안을 구체화한 것이다.

> *「학습자가 실시간으로 모르거나 질문이 생길때 웹 안에서 그걸 해결할수있고 서술형응답이나
> 학습자의 최종 해석과 기록물을 평가하고 추후 통계적 분석을 통해서 학습효과분석 또는
> 학습자 맞춤형으로 교육을 제공할 수 도 있고 많지」*

원고에 쓴 근거와 조건:

- **근거** — 용어에 관한 요구는 뜻풀이를 보완한 뒤에도 같은 형태로 남았고(4.7), 요구의
  성격은 낱말의 뜻이 아니라 탐구 과업 전체의 수준에 있었다(5.4). 화면에 미리 얹는
  설명으로 도달하지 못하는 부분이 있다.
- **쓸 수 있는 방향 셋** — ① 학습자가 막힌 지점에서 묻고 답을 받는다 ② 서술형 기록과
  최종 해석을 검토해 되짚어 준다 ③ 축적된 기록을 분석해 어느 단계에서 어떤 어려움이
  반복되는지 확인하고 안내의 양을 학습자에 따라 달리 둔다.
- **조건** — 5.2에서 다룬 균형과 정면으로 맞닿는다. 묻는 즉시 답을 주면 학습자가 직접
  세워야 하는 설명을 기능이 먼저 내놓는다. **학습에 관한 판단은 실제 학습자를 대상으로
  한 연구가 선행되어야 한다** — 이 논문은 학생 대상 조사를 하지 않았다.

## 4. 검사기 보강

「학습 효과」류 금지어 검사가 부정·유보 서술을 허용하는데 「선행되어야」가 목록에 없어
정당한 유보 문장을 잡았다. 「선행되어야 · 선행되는 · 판단할 수 없」을 허용에 넣었다.

## 남은 것 — 5장에 이 축이 없다

바이브코딩은 **서론 1.2 → 3.4 → 3.5·4.4 → 6장 → 고지 절**로 이어지는데 **5장에만
한 줄도 없다.** 서론이 던진 논점을 5장이 받지 않고 6장이 바로 결론을 낸다. 모래시계
구조에서 5장이 다시 넓어져야 하는 자리다. 소유자와 상의 중이며, 넣을 경우 다룰 것은
두 가지다.

1. 확인이 「문헌값을 재현하는가」가 아니라 「차이가 어느 처리에서 생기는지 특정되는가」였다.
2. 개발이 빨라진 대가로 검토 대상이 고정되지 않는다. 이 연구의 두 조사도 서로 다른
   빌드였고 성단 등시선 맞춤은 1차 검토 뒤에 만들어졌다(5.5 여섯째). 그래서 배포 시점과
   빌드를 기록하는 것이 방법의 일부가 된다.
