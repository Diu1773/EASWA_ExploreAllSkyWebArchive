# 부록 B. 예비교사 서술형 응답별 판정표

보완본에 대한 예비교사 재평가(4.7)의 서술형 응답을 부록 A와 같은 형식으로 정리한 기록이다. ID 표기는 부록 A와 같되 원본 응답 순서 R 대신 제출 시각 순서 P를 쓰며, P번호는 개인 식별자가 아니다. 원문은 오탈자와 문장부호를 포함해 그대로 옮겼다.

부호화는 지시적 내용분석(Hsieh & Shannon, 2005)의 절차를 따랐다. 표 4-11에서 현직 코호트 응답으로 확정한 13개 범주를 초기 부호로 두고, 한 응답이 두 가지 이상을 말하는 경우 의미 단위로 나누어 각각 배정하였다. 기존 범주에 들어가지 않는 진술은 새 범주로 추가하였다(아래 B.4).

**내용 있는 응답 52건**(문항 6은 12건, 20은 4건, 20-1은 12건, 22는 12건, 23은 12건)을 **의미 단위 78개**로 나누었다. 문항 19에서 8명이 '특별히 어려운 단계 없음'을 선택하여 문항 20의 응답 대상이 아니었다.

**판정 칸은 비어 있다 — 연구자가 채운다.** 「범주(초벌)」은 연구자 판정을 위한 제안이며 확정값이 아니다.
