# 서술형 응답 범주의 정의와 포함 기준 — 초안 (2026-09-09)

표 4-9의 20개 범주에 대해 **정의**(이 범주가 무엇을 가리키는가)와 **포함 기준**(어떤 응답을
여기 넣는가)을 적었다. 초안은 각 범주에 실제로 묶인 의미 단위에서 뽑았고, 연구자가
확인·수정한 뒤 3.6에 표로 싣는다.

- **★ 표시**는 인접 범주와 갈리기 쉬운 곳이다. 여기만 보아도 된다.
- 나머지는 의미 단위가 한 방향이라 초안대로 두어도 무방하다.

### ★1. 용어·기호·단위의 뜻 ↔ 사전 개념·통계 지식·전공 배경

연구자가 판정 항목 6에서 직접 고민한 구분이다 — *「용어해설을 추가했는데도 해설문제가
아니라, 그냥 용어 자체가 문제인듯」*.

| | 정의 | 포함 기준 |
|---|---|---|
| **용어·기호·단위의 뜻** | 화면에 제시된 **개별 표기**의 의미를 모르는 것 | Rp/R\*·BTJD·χ² 같은 기호, 축 이름, 단위처럼 **낱말 하나하나**의 뜻을 묻거나 설명을 요구한 진술 |
| **사전 개념·통계 지식·전공 배경** | 탐구를 수행하려면 **미리 알아야 하는 개념 전체** | 식현상·차등측광·통계처럼 **개념 덩어리**의 선행 학습이나 배경지식을 말한 진술 |

**가르는 물음**: 용어 목록에 한 줄을 더하면 풀리는가? 풀리면 앞, 안 풀리면 뒤.

## 나머지 여덟 — 의미 단위가 한 방향이라 초안대로 두어도 된다

| 범주 | 정의 | 포함 기준 |
|---|---|---|
| 예시 답안 제공 | 서술형 문항에 참고할 답이 없다는 지적 | 예시 답안·모범 답안을 요구한 진술 |
| 단계 이탈 위험 | 한 단계에서 막혔을 때 이후 전체를 포기할 위험 | 특정 단계의 실패가 이후 수행에 미칠 영향을 말한 진술 |
| 교사의 설명 준비 | 교사가 따로 준비해야 하는 설명과 자료 | 교사 설명 없이는 어렵다, 추가 설명을 덧붙여야 한다는 진술 |
| 자료 선택의 여지 | 고를 수 있는 탐구 대상·자료가 적다는 지적 | 자료 선택지의 수를 언급한 진술 |
| 긍정 평가 | 플랫폼의 장점이나 활용 가능성에 대한 긍정 | 실제 자료, 코딩 없는 분석, 단계 구조와 직접 조작을 긍정한 진술 |
| 학습자의 흥미·동기 | 학습자의 참여 의지에 관한 언급 | 흥미·동기의 차이를 든 진술 |
| 기존 서비스의 실행 부담 | 기존 서비스를 쓰는 데 드는 절차상의 부담 | 자료 내려받기·코딩·인터페이스 진입을 든 진술 (문항 6) |
| 기존 서비스의 영어·용어 장벽 | 영어 인터페이스와 전문 용어로 인한 어려움 | 언어와 용어를 직접 언급한 진술 (문항 6) |
| 기존 서비스의 수업 운영 조건 | 학급 규모·차시·교사 지도의 한계 | 수업 운영 조건을 든 진술 (문항 6) |
